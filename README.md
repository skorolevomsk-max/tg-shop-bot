# Telegram-бот «Магазин цифровых товаров»

Публичный бот-маркетплейс цифровых товаров на **aiogram 3.26.0** + **SQLite**.
Всё в одном файле `bot.py`. Разметка сообщений — HTML, валюта — ₽.

## Возможности

- `/start` — главное меню:
  - 🛒 Каталог (с пагинацией), покупка за внутренний баланс
  - ➕ Продать товар (название → описание → цена → контент)
  - 👤 Мой профиль (баланс, комиссия)
  - 💰 Пополнить (CryptoBot или перевод на карту админа)
  - 💸 Вывести (на карту, ФИО, банк; комиссия настраивается)
  - 📦 Мои товары
- `/admin` — админ-панель:
  - 📊 Статистика
  - 📣 Рассылка (copy_message, отправляется всем)
  - 💵 Выдать баланс
  - 💳 Реквизиты для ручного перевода
  - 📦 Товары (одобрить/отклонить/снять/вернуть/удалить/поменять цену)
  - ⚙️ Комиссия на вывод
- Модерация товаров в канале логов: карточка товара с материалом
  (медиа/текст/файл) + кнопки «Одобрить» / «Отклонить».
  После одобрения кнопка заменяется на «✅ Одобрено», после отказа — «❌ Отклонено».
- Ручные пополнения и заявки на вывод так же уходят в канал логов
  с кнопками подтверждения.

## Установка

```bash
git clone <репо> tg-shop-bot
cd tg-shop-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env
python bot.py
```

## .env

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — tg id админов через запятую (они видят /admin и модераторские кнопки)
- `LOG_CHANNEL_ID` — канал для модерации (бота добавить админом, скопировать `-100...` id)
- `CRYPTO_PAY_TOKEN` — токен @CryptoBot (опционально; если пусто — метод скрыт)
- `CRYPTO_PAY_TESTNET` — `true/false`
- `DB_PATH` — путь к файлу SQLite (по умолчанию `shop.db`)

## Команды

- `/start` — главное меню (для всех)
- `/admin` — админ-панель (только для `ADMIN_IDS`)

Команды появляются в подсказках при вводе `/`. Для админов показывается
расширенный список (через `BotCommandScopeChat`).

## Деплой

Подойдёт любой хост с Python 3.10+. Запускайте `python bot.py` как systemd
unit / в `tmux` / через `pm2`. Файл БД сохраняется в `DB_PATH` — бэкапьте его
вместе с `.env`.
