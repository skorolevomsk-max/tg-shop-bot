# 🎓 Course Shop Bot (Telegram)

Telegram-бот для продажи обучающих курсов (например, по маникюру). Закрытый каталог
(админ добавляет курсы и уроки), оплата через CryptoBot или ручной перевод на
карту, промокоды на скидку, реферальная программа с % продавцу.

Стек: Python 3.10+, aiogram 3.26.0, SQLite (aiosqlite), HTML-разметка, один файл.

## Возможности

**Для учеников:**
- Просмотр каталога опубликованных курсов
- Подробная страница курса с перечнем уроков и бесплатными пробными уроками
- Покупка курса через CryptoBot (фиат RUB) или ручным переводом с пруфом
- Применение промокодов на скидку
- Раздел «Мои курсы» с доступом к урокам (видео/фото/PDF/текст)
- Реферальная программа: ссылка с `?start=ref_<tg_id>`, % автоматом на баланс
- Вывод реферального баланса на карту

**Для админа:**
- `/admin` (команда скрыта от обычных пользователей)
- Статистика, рассылка, настройка приветствия
- CRUD курсов и уроков, публикация/снятие с публикации, перестановка уроков
- Бесплатные уроки (пробные) — отмечаются в админке
- Создание и деактивация промокодов (с лимитом использований)
- Реквизиты для ручной оплаты
- Настройка % реф. комиссии
- Ручная выдача курса пользователю (без оплаты)
- Модерация оплат и заявок на вывод прямо в логовом канале

## Установка

```bash
cd course-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN, ADMIN_IDS, LOG_CHANNEL_ID, (опц.) CRYPTO_PAY_TOKEN
python bot.py
```

## .env

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_IDS` | TG id админов через запятую |
| `LOG_CHANNEL_ID` | ID канала логов (`-100xxxxxxxxxx`), бот должен быть админом с правом «Post messages» |
| `CRYPTO_PAY_TOKEN` | Токен из @CryptoBot → Crypto Pay → Create App (опц., без него метод скрыт) |
| `CRYPTO_PAY_TESTNET` | `true` для testnet-pay.crypt.bot/api |
| `DB_PATH` | Путь к SQLite (по умолч. `course.db`, на Fly.io — `/data/course.db`) |

## Команды

- `/start` — главное меню (для всех)
- `/admin` — админ-панель (только у `ADMIN_IDS`)

## Как пользоваться (краткий сценарий)

1. Задайте в `/admin → Реквизиты` реквизиты для ручной оплаты.
2. Создайте курс через `/admin → Новый курс` (название, описание, цена, обложка).
3. Добавьте уроки через карточку курса (видео/PDF/текст + пометка «бесплатный» для пробных).
4. Опубликуйте курс. Появится в каталоге.
5. Ученики покупают курс → оплата проверяется в канале логов — нажимаете
   «Подтвердить оплату» → курс автоматически открывается в «Мои курсы».
